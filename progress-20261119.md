## C0.1: versioned generation presets (refactor only)

**Summary.** The sampling ranges (`presets.py`) and labeller constants (`label.py`) move
into a frozen `presets.Preset` dataclass. `P01` holds the 0.1 values, and `PRESETS` maps
names to presets.
- The preset is a required keyword argument of `items.sample_item`,
  `label.evidence`/`label_runs`, `confusers.check_item` and `pipeline.label_indices`.
- Worker processes receive the preset's name and look it up in `PRESETS`, because a
  `MappingProxyType` field does not pickle. `label_indices` refuses a preset that is not
  registered.
- `scripts/label_items.py`, `audit_items.py`, `ramp_sweep.py` and `gb2_sweep.py` pass
  `P01` explicitly. No CLI change: a `--preset` flag arrives with P02.

**Decisions:**
- **Plant constants are not in the preset.** Sensor and load noise, drum model, three-element
  control, day length and rated MW are hotwell configuration copied from v0.4.0 and
  shared by every preset. `check_upstream_copies.py` still checks them as module
  constants.
- **The builder does not take a preset.** Plan §4 said "sampler, builder and labeller",
  but `build.py` reads only plant constants. Everything it builds comes from the
  `ItemRecord`, so passing a preset to it would be unused.
- **No default preset.** A default would let 0.2 code silently generate 0.1 items.
- **`SENSOR_BIAS_X` removed.** It was an unused alias of `MAG_RANGE`. Its meaning
  (sensor bias = ratio × D_i) is now documented on `Preset.mag_range`.

## C0.2: master seed from a file in label_items.py

**Summary.** `scripts/label_items.py` takes the seed from `--master N` or from
`--master-seed-file PATH`; exactly one is required. `--split test` refuses `--master`,
because a seed on the command line is visible to anything that lists processes (the
progress-20261108.md incident).
- The file format is the one `package_split.py` reads: one non-negative integer,
  surrounding whitespace allowed.
- `read_seed` rejects anything else without echoing the file's content.
- `run.json` still records only the seed's SHA-256.

**Decision.** `--master` stays for dev, whose seed (20261107) is public and appears in
the 0.1 docs. The dev commands in the logs keep working.

**Verification:**
